## View Commit Log

Se puede explorar el historial de confirmaciones completo. Las ramas se muestran mediante un gráfico que resalta las confirmaciones que se incluyen en la revisión actual.

![View commit](https://gitextensions.github.io/images/commitlog205.png)

## File History

Explore the history of single files. Renamed and moved files are matched and shown in a single history. You do not need to mark files as renamed/moved. The system detects renamed files automatically.

![File History](https://gitextensions.github.io/images/FileHistory205.png)

## Blame

Find the last person who edited a specific part of a file. Double-click on the line to show the commit and allow you to drill down to other files.

![Blame](https://gitextensions.github.io/images/Blame205.png)
